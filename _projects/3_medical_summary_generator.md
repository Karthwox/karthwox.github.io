Medical reports are written for clinicians, so the people they're about often can't make sense of them. This is a local web application that takes raw medical data and uses LLM APIs to produce a plain-language summary, so someone without medical training can understand what a report says.

It runs locally, with a Python back end calling the LLM APIs and a simple HTML, CSS and JavaScript front end.

_Built in 2025 as a personal project. The summaries explain a report; they are not medical advice._
